ⓘ How to Read This Report

Execution Status

  • Pass  — test case executed and passed all success criteria.
  • Fail  — test case executed but one or more success criteria were not met.
  • Not Executed  — test case has not been run yet.
  • Blocked  — test case cannot be executed due to a dependency or environment issue.

Row Highlighting in the Detail Table

  • Red row  — Fail or Blocked test case with no defect mapped. Action required: link a defect ticket.
  • Yellow row  — Not Executed test case (pending execution).
  • No highlighting — Pass, or Fail/Blocked with a defect already mapped.

Fix Version / Release Tag

The Fix Version shown in the Report Parameters table and the Test Run Overview is taken from the fixVersions JIRA field of each Test Run issue. It identifies the product release label (e.g. AM2CG_26.01.00) against which the test run was executed. When multiple test runs are provided, all unique fix versions are shown comma-separated.
